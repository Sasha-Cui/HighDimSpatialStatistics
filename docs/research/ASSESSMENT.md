# Publishability assessment

## Executive decision

The existing repository does **not** support a publishable statistical paper in
its current form, and none of its archived numerical results should be reported.
There is no repository-authored theorem or proof; the main model and two-stage
fitting algorithm are already in Apanasovich, Genton, and Sun (2012); the main
synthetic pipeline used incompatible vector orderings, erased negative
cross-covariances, differentiated the Matérn kernel incorrectly, and fitted
smoothed observations with the wrong covariance.

The project should be **continued only after narrowing it**. The strongest
feasible paper direction is:

> A Matérn-specific analysis of the pseudo-true parameter shift and information
> loss caused by local spatial smoothing, with an exact change-of-support
> likelihood, an explicit bias expansion or strict target-displacement theorem,
> and a fixed-​\(p\) multivariate extension.

The identity \(\operatorname{Cov}(SY)=SKS^\top\) and a corrected likelihood are
standard, not novel. The paper is viable only if it proves a sharper result such
as an explicit nonzero Matérn target shift, a bandwidth-dependent bias expansion,
or a new multivariate information-loss theorem. If that result cannot be proved
and the corrected method is not computationally competitive, the methodological
paper should be abandoned. The repository can still become useful software or a
reproducibility case study, but it should not be marketed as high-dimensional
statistics.

## 2. Formal reconstruction of the intended project

### 2.1 Statistical model

At locations \(s_1,\ldots,s_n\in D\subset\mathbb R^d\), the intended latent
process is a stationary, isotropic, zero-mean, \(p\)-variate Gaussian field

\[
Z(s)=\{Z_1(s),\ldots,Z_p(s)\}^{\mathsf T}.
\]

The intended cross-covariance is

\[
C_{ij}(h;\theta)
=
\sigma_{ij}
\frac{2^{1-\nu_{ij}}}{\Gamma(\nu_{ij})}
\bigl(\alpha_{ij}\lVert h\rVert\bigr)^{\nu_{ij}}
K_{\nu_{ij}}\!\bigl(\alpha_{ij}\lVert h\rVert\bigr),
\tag{1}
\]

where \(\alpha_{ij}>0\) is a **decay scale** (larger means faster decay),
\(\nu_{ij}>0\) is smoothness, \(\sigma_{ii}\) is a marginal variance, and
\(\sigma_{ij}\) is a signed co-located covariance. Equation (1), including this
scale convention, is the flexible multivariate Matérn model of
[Apanasovich, Genton, and Sun (2012)](https://doi.org/10.1080/01621459.2011.643197).

The implementation omits an explicit mean and scientific observation model. A
defensible real-data formulation would instead be

\[
Y_i(s)=m_i(s,x_s)+Z_i(s)+\varepsilon_i(s),
\qquad
\operatorname{Cov}\{\varepsilon(s)\}=\Psi,
\tag{2}
\]

with a spatial/cell-type mean \(m_i\), measurement noise \(\Psi\), and a clear
statement of what the log-normalized transcriptomic values represent. Neither
\(m_i\) nor \(\Psi\) is currently estimated.

### 2.2 Validity parameterization

The intended sufficient construction is

\[
\nu_{ij}=\frac{\nu_i+\nu_j}{2}
+\Delta_A(1-R_{A,ij}),
\tag{3}
\]

\[
\alpha_{ij}^2=\frac{\alpha_i^2+\alpha_j^2}{2}
+\Delta_B(1-R_{B,ij}),
\tag{4}
\]

and

\[
\sigma_{ij}=W_iW_jR_{V,ij}
\alpha_{ij}^{-2\Delta_A-\nu_i-\nu_j}
\frac{
\Gamma\{(\nu_i+\nu_j)/2+d/2\}\Gamma(\nu_{ij})
}{
\Gamma(\nu_{ij}+d/2)
}.
\tag{5}
\]

Here \(R_A,R_B\) are valid correlation matrices with nonnegative entries,
\(R_V\) is a valid correlation matrix, and \(\Delta_A,\Delta_B\ge0\). The source
code replaces each matrix by one scalar equicorrelation parameter and retains
free \(W_i\)'s while overwriting the diagonal of (5). That is not a faithful
globally valid parameterization.

### 2.3 Objective and estimator

For a correctly stacked observation vector

\[
y=\operatorname{vec}_{\mathrm{location}}(Y)
=
(Y_1(s_1),\ldots,Y_p(s_1),Y_1(s_2),\ldots,Y_p(s_n))^\top,
\]

the exact zero-mean Gaussian negative log-likelihood is

\[
\ell_n(\theta)
=\frac12y^\top K_\theta^{-1}y
+\frac12\log\det K_\theta
+\frac{np}{2}\log(2\pi).
\tag{6}
\]

The intended estimator has two stages already prescribed by the 2012 paper:

1. Fit \((\alpha_i,\nu_i,\sigma_i)\) marginally for every component.
2. Plug those estimates into (3)--(5) and optimize the cross parameters.

The repository then uses two computational approximations:

- pairwise distances are rounded to a grid before evaluating the Matérn
  function;
- data are partitioned into batches or smoothed onto several grids and the
  within-group likelihoods are summed while cross-group covariance is omitted.

The random-partition version is a block-independence composite likelihood, not a
stochastic gradient of (6). The multiresolution smoothing version is more
severely misspecified. If a grid response is

\[
\widetilde Y_g=S_gY,
\]

then, using location-major stacking and \(A_g=S_g\otimes I_p\),

\[
\operatorname{Cov}(\operatorname{vec}\widetilde Y_g)
=A_gK_\theta A_g^\top,
\qquad
\operatorname{Cov}(\widetilde Y_g,\widetilde Y_h)
=A_gK_\theta A_h^\top.
\tag{7}
\]

The original code instead used a new Matérn matrix at the grid coordinates and
treated the overlapping grids as independent batches.

### 2.4 Claimed outputs

The synthetic validation target is mostly relative squared Frobenius error,

\[
d_F(\widehat K,K_0)=
\frac{\lVert\widehat K-K_0\rVert_F^2}{\lVert K_0\rVert_F^2}.
\tag{8}
\]

There are exploratory notebooks for permutation testing, learned pseudo-distance,
boundary detection, and teleconnections. None defines a valid estimator and null
hypothesis with calibrated error control. No repository result establishes a
rate, confidence interval, support-recovery guarantee, prediction improvement,
or minimax lower bound.

### 3.2 Exact failure points

1. **Scale reversal.** AGS uses \(\alpha r\); original package code used
   \(\sqrt{2\nu}r/\alpha\). Applying (3)--(5) to that `alpha` does not inherit
   the AGS validity theorem.
2. **Sign erasure.** Values \(-0.286\) and \(-0.181\) in the synthetic “truth”
   became positive after squaring.
3. **Permutation.** A block matrix indexed as \((i,s)\) was sampled and reshaped
   as if indexed \((s,i)\). A direct audit of 30 archived raw datasets found that
   the induced permutation had lower mean NLL than the claimed layout
   (approximately 830.9 versus 869.1), confirming the stored data follow the bug.
4. **Gradient.** The order derivative of \(K_\nu(x)\) was replaced by the argument
   derivative; numerical discrepancies reached orders of magnitude and sometimes
   the wrong sign.
5. **Archived benchmark contamination.** Some Python-versus-R covariance metrics
   compare an estimate with `true_K` evaluated at newly generated, unrelated
   locations. Older outputs also match the legacy alpha/nu-swapped kernel rather
   than the cleaned nominal kernel.
6. **Cross-parameter identifiability.** Only
   \(\Delta_B(1-\rho_B)\) appears; \(\Delta_B\) and \(\rho_B\) cannot be separately
   estimated. Free \(W_i\) and \(\rho_V\) have a product scaling confounding after
   diagonals are overwritten. The scalar equicorrelation constraint also requires
   \(\rho_V\ge-1/(p-1)\), not merely \(\rho_V>-1\).
   Moreover, positive \(W_i\) and one scalar \(\rho_V\) force every off-diagonal
   covariance to share a sign, so the bundled \((-,-,+)\) Genton pattern is
   outside the fitted family.
7. **Optimizer bookkeeping.** Early stopping uses only the final batch, Adam
   moments are not restored after rejected steps, reduced learning rates are reset,
   and checkpoints do not pair the best loss with a best-state snapshot.
8. **Smoothing.** The same observations appear in ten overlapping resolutions.
   Their correct cross-covariance is nonzero in (7), so their likelihood terms
   cannot be interpreted as independent replicates.
9. **Mean/nugget misspecification.** Gene-expression gradients, tissue domains,
   cell composition, and transformed count noise are absorbed into a stationary
   zero-mean covariance with only numerical jitter.
10. **Incomplete artifacts.** No successful cross-fit result is present. Synthetic
    and real best-parameter tables are mostly/all missing values, validation
    outputs are absent, and many loss traces terminate without a calibrated
    stopping or held-out criterion.

### 3.3 Asymptotic audit

The synthetic domain remains \([-3,3]^d\) while \(n\) increases: this is infill,
not increasing-domain asymptotics. Under fixed-domain Matérn asymptotics,
variance and scale are generally not separately consistently estimable; the
relevant microergodic combination under the AGS decay convention is proportional
to \(\sigma^2\alpha^{2\nu}\) when \(\nu\) is fixed. This is a classical obstacle,
not a technicality; see [Zhang (2004)](https://www.stat.purdue.edu/~zhanghao/Paper/JASA2004.pdf).

No minimum-separation condition, mixing coefficient, boundary growth condition,
effective block count, compact parameter space, uniform eigenvalue bound,
identifiability condition, or \(p=p_n\) regime is stated. Consequently, there is
no existing pointwise, uniform, asymptotic-normal, or minimax claim to repair.

### 3.4 Experiment-to-claim audit

- All six archived `K_test` marginal covariances match the historical
  alpha/nu-swapped implementation to relative Frobenius error between roughly
  \(10^{-14}\) and \(3\times10^{-8}\). Reconstructing them under their documented
  parameters gives errors from 0.013 to 0.537. They are not truth matrices for the
  stated model.
- The 300 R/Python benchmark CSVs contain two coordinate designs. The aggregate
  metrics reuse incompatible truth coordinates, and Python reshapes gene-major
  long data as `reshape(200, 3)` rather than `reshape(3, 200).T`. R and Python also
  use different mean models. The reported 0.220 versus 0.133 comparison is void.
- The nominal 15,000/1,000 train/test split from 15,907 locations overlaps at 93
  coordinates. Independently simulated responses prevent ordinary response
  leakage, but it is not a disjoint spatial holdout.
- Legacy workflows multiply coordinates by 200 while the canonical preprocessor
  does not. Matérn decay/range estimates from those paths have incompatible units.
- Synthetic marginal directories contain many fit/loss files but no validation
  metrics; most stored best-parameter cells are missing. The real path completed
  only a small fraction of its planned hyperparameter-by-gene fits, with all
  stored best values missing. There is no successful cross-fit artifact.
- The one archived GPU log shows no GPU allocation/utilization; the SciPy Bessel
  wrapper also transfers values through CPU, so GPU scalability is not evidenced.

### 3.5 Exploratory branches excluded from the paper

The pseudo-distance, permutation, boundary, and teleconnection notebooks do not
hide a second completed paper. In particular, `np.polyfit` coefficients (descending
order) are passed to `numpy.polynomial.Polynomial` (ascending order), the learned
matrix is not constrained to satisfy triangle inequalities or Euclidean
embeddability, semivariogram monotonicity/update direction is inconsistent, and
teleconnection thresholds are acknowledged as arbitrary. The permutation test
does not justify spatial exchangeability or multiplicity control. Archive these
ideas; combining them with the primary direction would weaken both stories.

### Conservative novelty statement

> Known linear smoothing is a change-of-support Gaussian-process observation
> model; covariance propagation through \(SK_\theta S^\top\), corrected Gaussian
> likelihood, and generic KL pseudo-targeting are established. The possible new
> contribution is a sharp Matérn-specific characterization of target shift and
> information loss under local spatial preprocessing, including bandwidth,
> boundary, nugget, and multivariate cross-covariance effects.

Do not claim the first smoothing correction, first smoothing-aware GP, a new
multivariate Matérn, a new two-stage estimator, or a high-dimensional method.

## 5. Candidate paper formulations

### Direction A (recommended): Matérn inference after local spatial smoothing

**Main contribution.** Characterize the pseudo-true parameter obtained when
locally smoothed Matérn observations are naively fitted as point observations,
and compare it with the exact observation-operator likelihood. The headline must
be an explicit nonzero target shift or bias expansion, not equation (7).

**Core assumptions.** Fixed \(p\); stationary Matérn latent field with compact
interior parameter \(\theta_0\); known or separately identified mean and nugget;
increasing rectangular domain with bounded sampling density and minimum spacing;
translation-invariant, deterministic interior smoother \(S_{n,h}\); bandwidth
either fixed or obeying a declared \(h_n\) regime; uniformly bounded covariance
spectra; identifiable naive and corrected criteria; boundary fraction tending to
zero. Fixed-domain results must target microergodic combinations only.

**Required proofs.** Linear transformation lemma (routine); spectral expression
\(f_h(\omega)=|H_h(\omega)|^2f_{\theta_0}(\omega)\) (routine); KL pseudo-target
criterion (known framework); strict target displacement; explicit expansion
\(\theta^*(h)-\theta_0=h^qB(\theta_0)+o(h^q)\) with \(B\ne0\); boundary remainder;
corrected-estimator consistency/CLT or a composite-likelihood analogue; optional
fixed-domain microergodic corollary; multivariate cross-parameter extension.

A concrete proof foothold already exists. For the one-dimensional
Matérn-\(1/2\) covariance \(C(r)=\sigma^2e^{-\alpha|r|}\) and continuous
Epanechnikov smoothing, if \(U,V\) have density
\(\kappa(u)=\tfrac34(1-u^2)1\{|u|\le1\}\), then

\[
\operatorname{Var}\{Z_h(s)\}
=\sigma^2\mathbb E e^{-\alpha h|U-V|}
=\sigma^2\left\{1-\frac{18}{35}\alpha h+O(h^2)\right\}.
\]

This proves nonzero first-order variance distortion in one special case. The
paper still needs the induced joint parameter target, range/smoothness effects,
boundaries, and the multivariate extension.

**Simulations/application.** Increasing versus fixed domain; \(n\), bandwidth,
smoothness, range, nugget, anisotropy/nonstationarity, boundaries, irregular
design, and \(p\); naive versus corrected versus unsmoothed oracle; exact versus
composite implementation; replicated SRT data with spatially separated or
sample-level holdout.

**Baselines.** Exact unsmoothed Matérn, naive smoothed-point fit, exact
change-of-support fit, block composite likelihood, Vecchia/SPDE where scaling is
claimed, and Smoothie/COVET/SpaceX/spMOCA for biological analyses as appropriate.

**Figures/tables.** Bias versus bandwidth with theorem slope; pseudo-target
contours; coverage and RMSE; information/effective sample size; boundary heatmap;
runtime/memory; multivariate cross-correlation recovery; biological replicate
stability and held-out prediction.

**Principal risk.** The main ingredients are established. Without an explicit
new target-shift theorem or multivariate information result, the paper is too
incremental.

**Minimum publishable result.** A nonzero Matérn-specific bias expansion plus a
corrected increasing-domain estimator, honest uncertainty, comprehensive
simulation, and one replicated scientific application.

**Ambitious extension.** Joint bandwidth/parameter estimation, irregular
boundary correction, and multivariate microergodic information bounds.

### Direction B: PSD-preserving distance approximation with inference guarantees

**Main contribution.** Replace nearest-bin entrywise rounding and eigenvalue
shifting by a projectively valid, PSD-preserving Matérn approximation and prove
kernel, likelihood, score, and estimator perturbation bounds.

**Assumptions.** Compact parameter set; fixed \(p\); distances in a controlled
range; nugget/eigenvalue margin \(\kappa>0\); uniform Hölder regularity in distance;
identified, locally strongly convex likelihood; approximation resolution tied to
\(n,p\).

**Required proofs.** Uniform entry error; spectral error; PSD preservation;
log-determinant/inverse perturbation; score/Hessian error; argmin stability; if
asymptotic equivalence is claimed, approximation error \(o(n^{-1/2})\) at the
score level.

**Simulations/baselines.** Exact dense likelihood, current nearest lookup,
interpolation, Vecchia, tapering, SPDE, spectral/Fourier approximations, and
modern GP libraries. Report matched-error runtime and memory, not raw speed.

**Figures/tables.** Error-runtime frontier; minimum eigenvalue; gradient error;
parameter bias/coverage; scaling in \(n,p\); GPU/CPU breakdown.

**Principal risk.** Saving special-function calls while retaining dense
factorization may have negligible end-to-end value, and strong competing methods
already exist.

**Minimum publishable result.** A genuinely PSD construction, uniform estimator
bound, and a material speed/accuracy advantage over appropriate baselines.

**Ambitious extension.** Combine the approximation with sparse blocks or
hierarchical matrices and prove end-to-end near-linear complexity.

### Direction C: Sparse growing-\(p\) multivariate Matérn estimation

**Main contribution.** Introduce sparse graph, Cholesky, or factor structure for
cross-variable dependence and prove rates/support recovery for \(p=p_n\to\infty\)
under spatial dependence.

**Assumptions.** Increasing domain; bounded degree \(s\); restricted eigenvalue or
incoherence condition; bounded marginal/cross spectra; mixing; \(s\log p/n_{\rm
eff}\to0\); identifiable globally valid covariance; tuning selection and
beta-min for support recovery.

**Required proofs.** Uniform score concentration under spatial dependence,
restricted curvature, estimation/oracle inequalities, support recovery or
prediction risk, and possibly a matching lower bound.

**Simulations/application.** \(p\in\{20,50,100,250\}\), multiple graph topologies,
varying domain and dependence, misspecified sparsity, graphical GP/factor/basis
methods, and several replicated datasets.

**Figures/tables.** Phase diagram in \((n,p,s)\); support F1; covariance/precision
risk; calibration; runtime/memory; real network stability.

**Principal risk.** A 2026 regularized highly multivariate spatial GRF preprint
already covers LASSO-Cholesky multivariate Matérn likelihood/composite likelihood.
A distinct theorem and structure are required. This is effectively a new project.

**Minimum publishable result.** A clearly non-overlapping structural model with a
nonasymptotic rate and convincing large-\(p\) evidence.

**Ambitious extension.** Minimax lower bounds and adaptive graph recovery under
unknown spatial covariance.

## 6. Why Direction A is primary

Direction A has the best connection to the existing code and to a consequential
scientific error: smoothing is central to the current pipeline, and its
inferential distortion can be isolated. It is more feasible than new growing-\(p\)
theory and more statistically consequential than accelerating Bessel evaluations.
Its novelty is nevertheless conditional. A four-week analytical feasibility gate
must establish an explicit target shift or bias coefficient. Failure at that gate
should trigger abandonment of Direction A, not a weaker claim that (7) is new.

## 7. Proof-completion plan

1. Freeze one univariate Matérn convention and a translation-invariant smoother
   on a regular increasing-domain lattice.
2. Write the expected naive likelihood in spectral form and derive the score at
   \(\theta_0\). Establish a parameter/smoother configuration for which it is
   provably nonzero.
3. Expand \(|H_h(\omega)|^2\) near \(h=0\), justify differentiation under the
   integral, and solve the implicit score equation for the first nonzero bias
   term.
4. Separate fixed \(h\), vanishing \(h_n\), and fixed-domain microergodic regimes.
5. Bound row-normalization and boundary errors relative to the stationary
   interior approximation.
6. Establish corrected M-estimator consistency and Godambe/likelihood CLT under
   an explicit block design; label standard imported arguments honestly.
7. Extend from scalar spectra to a fixed-dimensional spectral matrix and identify
   which cross parameters have a nonzero shift.
8. Add numerical symbolic checks and adversarial counterexamples at every step.

## 8. Simulation and empirical-validation plan

Every theoretical claim must map to a simulation panel. The minimum grid varies
domain regime, \(n\), bandwidth, Matérn smoothness/decay, nugget, dependence,
boundary geometry, irregularity, \(p\), and misspecification. Use at least 500
replicates for final bias/coverage claims unless Monte Carlo error calculations
justify fewer; report Monte Carlo standard errors and retain all failed fits.

The real-data analysis requires multiple independent slides/animals or a second
public dataset, predeclared genes/tasks, cell-type/region-aware mean structure,
sample-level validation, and established SRT baselines. A single puck cannot
support population-level biological claims. See
[SIMULATION_PROTOCOL.md](SIMULATION_PROTOCOL.md) for the exact claim matrix.

## 9. Repository and reproducibility plan

The preservation branch now corrects the unambiguous kernel, sign, stacking,
gradient, likelihood-dimension, and smoothing-operator defects and adds regression
tests. These repairs invalidate all old outputs rather than retroactively fixing
them. The legacy cross optimizer remains unfit for scientific use until its
parameterization and state management are replaced.

Next repository milestones are: a canonical configuration schema; immutable run
manifests; JSONL/Parquet metrics; a data registry with checksums and licensing;

## 12. Final continue/narrow/abandon rule

**Continue and narrow now.** Do not continue the current broad project and do not
submit any current results.

Proceed only if all three gates pass:

1. **Theory gate:** an explicit nonzero target displacement or bias expansion is
   proved under a defensible regime.
2. **Computation gate:** corrected inference is stable, calibrated, and not
   dominated by established change-of-support/GP methods.
3. **Evidence gate:** simulations reproduce the theorem and the application has
   independent replication plus meaningful baselines.
