# SupportShift clean entry point

This directory is the public front door for the SupportShift paper and
synthetic benchmark. The historical research pipelines elsewhere in the
repository are not part of the SupportShift evidence contract.

## What is in scope

- Paper sources: `paper/geosim2026.tex` and `paper/manuscript.tex`
- Mathematical implementation: `src/HighDimSpatial/smoothing_bias/`
- Audited generators: `scripts/research/run_*support*`,
  `run_multilag_composite_audit.py`, `run_full_likelihood_phase_audit.py`,
  `run_joint_smoothness_audit.py`, and `run_matched_boundary_audit.py`
- Promoted source data: `outputs/smoothing_bias/supportshift_*`
- Paper data and hashes: `paper/data/supportshift_artifact_manifest.json`
- One-command verification: `scripts/research/verify_supportshift_release.py`

The `legacy/` directory and root-level historical notebooks are explicitly out
of scope. They are retained only for provenance and are not called by any
SupportShift command below.

## Reviewer quick start

From the repository root:

```bash
python -m pytest -q \
  tests/test_smoothing_bias_continuous.py \
  tests/test_smoothing_bias_high_dimensional.py \
  tests/test_supportshift_scripts.py

python scripts/research/verify_supportshift_release.py \
  --metadata outputs/smoothing_bias/supportshift_highdim_final_v2_20260803.metadata.json \
  --paper-directory paper \
  --repository-root . \
  --require-full
```

The verifier checks input and output hashes, clean-run provenance, complete
factor grids, numerical gates, the 8,400 finite-grid fits, the 12,800
replicated-field fits, and every manuscript number registered in the claim
ledger.

## New referee-directed audits

Each command refuses a dirty worktree by default and emits a CSV plus a JSON
metadata record containing the generating commit and SHA-256 hash.

```bash
python scripts/research/run_multilag_composite_audit.py
python scripts/research/run_full_likelihood_phase_audit.py
python scripts/research/run_joint_smoothness_audit.py
python scripts/research/run_matched_boundary_audit.py
```

These runs address, respectively:

1. genuine multi-lag misspecification and its first nonzero KL term;
2. the finite-design full-Gaussian local projection theorem;
3. joint smoothness--decay fitting with an intermediate 75%-bandwidth method;
4. boundary effects at exactly matched output dimension.

## Synthetic-only scope

No empirical data set is required or claimed. All paper evidence is either a
deterministic quadrature calculation, an exact finite-design population target,
or a seeded Gaussian simulation generated by the released code.
